# 🏥 Medical AI Assistant using Machine Learning & Gemini AI

## 📌 Overview

Medical AI Assistant is an intelligent healthcare application that predicts diseases based on user symptoms using Machine Learning and provides detailed medical explanations using Google's Gemini AI.

The application combines classical Machine Learning with Generative AI to deliver accurate disease prediction along with easy-to-understand health information.

---

## 🚀 Features

- Disease Prediction using Machine Learning
- AI-powered explanation using Google Gemini
- Symptom-based diagnosis
- Treatment suggestions
- Precautions
- Diet recommendations
- User-friendly interface
- Fast prediction

---

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/vaishnava-oj/Medical_AI_Assistant.git
```

Go inside project

```bash
cd Medical_AI_Assistant
```

Install requirements

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```
